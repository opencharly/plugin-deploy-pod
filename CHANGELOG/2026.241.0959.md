# 2026.241.0959 — fix(deploy-pod): advance the spec/sdk pins and name a failed project connect

## Summary

`plugin-deploy-pod` pinned `spec v0.2026232.521` and `sdk v0.2026236.18` while charly has advanced to day-241 spec. Because `deployKeyToBoxLocal` degrades to `""` on **any** connect/load failure, that pin skew did not present as a version error — it presented as a bogus missing image:

```
charly: error: command "config": deploy:pod config: InvokeProvider deploy:pod op=config-setup:
  rpc error: code = Unknown desc = image not found in local storage:
  check-devops-layer:check-devops-layer-2026.241.0938
```

That ref was never built. The image that *was* built is `devops-layer-app:check-devops-layer-2026.241.0938` — the box name had silently degraded to the **deploy key**, because the project-fallback leg (`hostBuild` → `LoadUnifiedViaExecutor` → `ProjectFleetConfig`) failed on the wire-shape skew and returned `""`, which `resolveDeployBoxNameLocal` cannot distinguish from "this project declares no entry".

Three changes:

1. **Advance the pins** to `spec v0.2026241.931` / `sdk v0.2026241.933`.
2. **Name the cause where it is known.** A genuine transport/decode failure is not the same as "no entry declared"; conflating them is what turned a pin skew into a misleading `image not found`. The two error legs now warn with the deploy key, the underlying error, and the fact that a pin skew is the usual cause. The no-entry paths stay silent, so no existing quiet fallback becomes noisy. The two executor-backed legs become package-level vars (the seam idiom the sibling `config_setup` paths already use) so the failure branches are reachable from a test.

3. **Tests and one required migration.** New `resolve_ref_connect_failure_test.go` drives both failure branches and pins the no-entry path silent. `candy_by_name_test.go` is repointed from `spec.CandyMapKey` to `specfleet.CandyMapKey` — the helper moved to the `spec/fleet` package in the spec this branch advances to, so the package does not compile at the new pins without it.
