# 2026.270.1453 — fix(plugin-deploy-pod)!: ship a self-contained CUE schema (no schema-less plugin)

## Summary

Eradicate the schema-less plugin exception for `plugin-deploy-pod`, an ordered per-repo unit
of the R5 cutover tracked in **opencharly/charly#712**.

The SDK contract (**opencharly/sdk#314**, landed) changed `sdk.BuildCapabilitiesWithRequires`
to REJECT a `nil` schemaFS and an empty schema: every plugin MUST ship a non-empty,
self-contained CUE schema served over `Describe`. `plugin-deploy-pod` passed `nil` as the
schemaFS and served an EMPTY `schema_cue`.

This change:
- Adds `schema/pod.cue` — a package-less, self-contained CUE doc schema defining
  `#DeployPodPlugin` (the `deploy:pod` word, `lifecycle: true`, and a non-empty `contract`).
  It references no base def and compiles standalone.
- Embeds it with `//go:embed schema/*.cue` → `var schemaFS embed.FS` and passes `schemaFS`
  to `sdk.NewMeta` instead of `nil`.
- Corrects the stale `NewMeta` comment that claimed a "load-gate-only" schema the code did
  not serve.
- Adds `schema_serve_test.go` asserting `NewMeta().Describe` serves a non-empty schema
  carrying `#DeployPodPlugin` (fails without the change).

### Files changed — exact `git diff --name-status origin/main...HEAD`

- `candy/plugin-deploy-pod/go.mod` — **modified** (this PR): promotes `cuelang.org/go v0.16.1` from `// indirect` to a direct require (the new schema test imports `cuelang.org/go/cue` + `cuecontext`); **no new dependency**.
- `candy/plugin-deploy-pod/plugin.go` — **modified** (this PR): `//go:embed schema/*.cue` + `sdk.NewMeta(calver, caps, schemaFS)` replaces the trailing `nil`; the stale schema-less comment is corrected in place.
- `candy/plugin-deploy-pod/schema/pod.cue` — **NEW** (this PR): the plugin's self-contained served CUE schema (`#DeployPodPlugin`); references no base def, compiles standalone, and splices `base ++ plugin` at the host load gate (`registerPluginUnitSchema`).
- `candy/plugin-deploy-pod/schema_serve_test.go` — **NEW** (this PR): `Describe` MUST serve a non-empty `schema_cue` carrying `#DeployPodPlugin` (fails without the change).
